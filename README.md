# .github

Default [community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for every public repository under [github.com/ikrishg](https://github.com/ikrishg).

GitHub applies these defaults to public repos under the account that do not define their own: code of conduct, security, support, funding, and issue and pull request templates. They are written for humans who report bugs and read docs, and for coding agents that open most pull requests. Per-repository agent instructions belong in each product repo, not here.

## Defaults GitHub copies into other repos

| File | Purpose |
| --- | --- |
| `CODE_OF_CONDUCT.md` | Community standards |
| `PULL_REQUEST_TEMPLATE.md` | What to put in a pull request |
| `SECURITY.md` | How to report vulnerabilities privately |
| `SUPPORT.md` | Where to ask for help |
| `FUNDING.yml` | GitHub Sponsors button |
| `.github/ISSUE_TEMPLATE/` | Bug and feature request forms |

`LICENSE` is only for this repository. GitHub does not copy it into other projects under the account.

## Label names

`config/labels.json` lists the label names, descriptions, and colors used by the issue templates here. Other repositories can copy or sync the same file so names stay aligned with [ikrishg/config-github](https://github.com/ikrishg/config-github/blob/main/config/labels.json).
