# .github

Default [community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for every public repository under [github.com/ikrishg](https://github.com/ikrishg).

GitHub copies these defaults into repos that do not define their own. They are written for humans who report bugs and read docs, and for coding agents that open most pull requests. Per-repository agent instructions belong in each product repo, not here.

## What lives here

| File | Purpose |
| --- | --- |
| `CODE_OF_CONDUCT.md` | Community standards |
| `GOVERNANCE.md` | Who decides and how changes land |
| `LICENSE` | Default license text |
| `PULL_REQUEST_TEMPLATE.md` | What to put in a pull request |
| `SECURITY.md` | How to report vulnerabilities privately |
| `SUPPORT.md` | Where to ask for help |
| `FUNDING.yml` | GitHub Sponsors button |
| `.github/ISSUE_TEMPLATE/` | Bug and feature request forms |
